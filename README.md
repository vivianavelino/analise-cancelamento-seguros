#  Análise de Cancelamento de Clientes — Seguradora Atlas

Este projeto analisa dados de clientes de uma seguradora com o objetivo de identificar os principais motivos de cancelamento e investigar fatores associados à saída dos clientes.

##  Sobre os dados
Este projeto utiliza dados sintéticos para fins de estudo e prática de análise de dados.

##  Tecnologias
- Python
- Pandas
- Matplotlib
- Seaborn

##  O que foi realizado
- Auditoria e limpeza dos dados
- Tratamento de valores ausentes e inconsistências
- Análise exploratória
- Análise de fatores associados ao cancelamento
- Visualização dos resultados

## Principais resultados

- O preço, foi o maior motivo do cancelamento
- Seguro auto foi o mais vendido
- O uso do aplicativo não apresentou uma diferença significativa na retenção dos clientes.
- O Seguro vida apresentou a maior taxa de cancelamento com 24.58%
